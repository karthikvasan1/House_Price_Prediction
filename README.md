# 🏠 House Price Prediction Using Machine Learning

## 📌 Project Overview
This project aims to predict house prices using Machine Learning techniques. The model analyzes various housing features such as bedrooms, bathrooms, living area, floors, waterfront view, condition, and construction year to estimate property prices accurately.

## 🎯 Objectives
- Analyze housing market data
- Perform data cleaning and preprocessing
- Train a Machine Learning model for price prediction
- Evaluate model performance using regression metrics
- Generate house price predictions based on property features

## 🛠 Technologies Used
- Python
- Pandas
- NumPy
- Scikit-Learn
- Google Colab
- Machine Learning

## 📊 Dataset Features
The dataset includes:
- Bedrooms
- Bathrooms
- Square Footage Living Area
- Lot Size
- Floors
- Waterfront
- View
- Condition
- Grade
- Year Built
- Year Renovated
- Location Information
- House Price (Target Variable)
